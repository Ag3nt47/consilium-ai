# Privacy

**Consilium collects nothing.** There are no accounts, analytics, telemetry, crash reporters or ads.

## What stays on your computer

- Your conversations, stored as files in the app's data folder. Delete a conversation in the app to remove it.
- Your preferences (theme, effects, update checks), stored in the app's local storage.

## What leaves your computer, and to whom

| When | What is sent | To |
| --- | --- | --- |
| You send a message to ChatGPT | The conversation so far | OpenAI, through the Codex CLI and your ChatGPT account. OpenAI's privacy policy applies. |
| You send a message to Claude | The conversation so far | Anthropic, through Claude Code and your Claude account. Anthropic's privacy policy applies. |
| You send a message to Gemini (if you added it) | The conversation so far | Google, through the Antigravity CLI (or the Gemini CLI) and your Google account. Google's privacy policy applies. |
| You press **self-check** | A one-line test message | Each AI in the council |
| An AI with Read, Edit or Full access works in a project folder | Whatever files that AI's tool reads there | That AI's company, as part of its turn |
| Once a day, if "Check for updates" is on | A request for the latest release (no identifying data beyond what any web request carries) | GitHub's public API |

Only the AIs you address receive a message. Turning off update checks in Settings stops the GitHub request.

## Credentials

Consilium never sees your OpenAI, Anthropic or GitHub passwords, keys or tokens. Sign-ins happen in each provider's own tool and browser page.
