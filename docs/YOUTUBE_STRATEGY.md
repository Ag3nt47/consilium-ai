## 2. Promotional Demo Video Scripts

### Video 1: "I Put 3 Frontier AIs in One Room and Told Them to Build an App"
**Duration:** ~5–7 minutes  
**Tone:** Fast-paced, developer-focused, technical yet accessible.

- **Scene 1 (0:00 - 0:45): The Cold Open**
  - *Visual:* Screen capture of Consilium desktop window in dark `glass` theme. Terminal drawer open.
  - *Voiceover:* "We all use ChatGPT, Claude, or Gemini for coding. But you usually paste code into one window, get an answer, find a bug, paste it into another window, and play telephone between three different models. What if you didn't have to? What if they all shared one room, one terminal, and one workspace?"
  - *Action:* The user types in Consilium: `Build a real-time host resource pressure gauge in Rust and React.`

- **Scene 2 (0:45 - 2:30): The Debate & The Devil's Advocate**
  - *Visual:* ChatGPT generates the initial Rust architecture. Immediately, Claude responds with a peer review pointing out memory pressure metrics on Apple Silicon. In round 3, Gemini receives the designated Devil's Advocate role.
  - *Voiceover:* "Consilium features a multi-round Discuss mode. Look at what happens in round 3: Consilium automatically assigns one model to be the Devil's Advocate. Gemini challenges the assumption that load average represents instantaneous core usage, forcing the team to sample `kern.memorystatus_vm_pressure_level`."

- **Scene 3 (2:30 - 4:00): Full Capacity Execution & In-Chat Approvals**
  - *Visual:* Red `REQUEST:` line appears with inline **Approve** and **Deny** buttons. User clicks **Approve**. Subprocess runs tests and compiles cleanly.
  - *Voiceover:* "With Full Capacity mode, the council can run commands, install software, and run tests. But critical security decisions are gated: whenever an AI needs human permission, it produces a red REQUEST box with native Approve and Deny buttons."

- **Scene 4 (4:00 - 5:30): Voice Chat & Conclusion**
  - *Visual:* User clicks "Switch to Voice Chat". User speaks: "Check if the test suite passes." The AIs respond aloud in spoken sentences with distinct native voices.
  - *Voiceover:* "Consilium is 100% open source, uses your own existing CLI sign-ins with no API keys required, and runs on macOS, Windows, and Linux. Star the repository on GitHub and download the release today."

## 4. Automation & Video Production Pipeline

### Automated Terminal Demo Recording
To quickly generate high-frame-rate, pixel-perfect demo clips of the terminal CLI (`consilium chat`) for video b-roll:
```bash
# Record an automated council session to cast
asciinema rec demo-session.cast -c "consilium chat"

# Render high-resolution SVG or MP4 animation
agg --theme monokai --font-size 18 demo-session.cast demo-session.gif
ffmpeg -i demo-session.gif -movflags faststart -pix_fmt yuv420p -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2" demo-session.mp4
```
